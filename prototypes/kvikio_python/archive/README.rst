Historical performance evidence
===============================

``performance-history.tar.gz`` consolidates 279 superseded tools, measurement
files, logs, reports, and local-only source snapshots. Every archived file was
verified against its original bytes before the loose copy was removed.

These records explain earlier measurements and are outside the runtime import
path. The current source, tests, and performance tools are in the parent
prototype directory. The unrelated package-wide experiment containing remote
and storage-format integrations has been removed.
